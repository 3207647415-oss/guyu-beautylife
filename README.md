# 肤知AI｜个人化护肤决策助手

肤知AI参赛 MVP 的公开体验版。它会结合演示用户的肤质、过敏史、特殊阶段和动态肤况，对产品成分表给出分级、可解释、可追溯的护肤建议。

## 在线体验

GitHub Pages 启用后，访问：

https://3207647415-oss.github.io/guyu-beautylife/

## 核心体验

- 配方安全审查：支持中英文及 INCI 成分名。
- 个性化规则：同一配方在不同肤况档案下会得到不同结论。
- 动态护肤档案：新增肤况快照后，基线和趋势图会同步变化。
- 可追溯证据：结论附带资料出处和适用边界。
- 隐私优先：体验数据只保存在访问者当前浏览器中。

## 重要说明

本项目是参赛 MVP，不构成医学诊断、处方或完整法规合规审查。出现持续不适、皮损或严重反应时，请停止使用并及时就医。
